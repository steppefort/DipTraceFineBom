# Перехід із BOMJob Python на FineBOM

[English](MIGRATION.md) · Українська · [README](../README_UA.md)

Для першої перевірки встановіть FineBOM в окрему папку плагіна. У DipTrace він
відображається як **FineBOM 0.1.1**. Наявне встановлення BOMJob можна залишити доступним
для порівняння результатів.

| BOMJob Python | FineBOM |
| --- | --- |
| `BOMJobAdapter.exe` та `adapter/` | `FineBOM.exe` і `.adapter` із репозиторію адаптера, додані під час збірки |
| Консольний засіб запуску `bomjob.py` | `plugin.py` із `main(ctx)`, який викликає `finebom.workflow.run(ctx)` |
| `bomjob.ini` | `finebom.ini` |
| `bomjob.project.ini` | `finebom.project.ini` |
| Старий `adapter.ini` з `mode=run`, `exe` та `script` | Налаштування API 1 адаптера з `mode=job`, `executable` та `entry` |
| Окреме читання середовища й відтворення через `environment.json` | `ctx.environment()`; явні значення середовища або INI для ручного запуску |
| Діагностика в старих каталогах захоплень BOMJob | Каталог запуску FineBOM у спільному адаптері |

Перенесіть налаштування BOM і секції замін до `finebom.ini`. Не копіюйте старий
`adapter.ini`: його формат належить попередньому засобу запуску. Повний типовий
файл налаштувань FineBOM входить до комплекту; переносити старі параметри запуску
чи виконувати `configure_quiet.py` не потрібно.

Комплектний `BOM.ots` не змінено порівняно з наданим пакетом BOMJob. За потреби
замініть його власним шаблоном і змініть `[plugin] template`. Відносні шляхи у
`finebom.ini` починаються поруч із цим файлом.

Збережено початкові правила відбору, групування, підрахунку кількості, червоні
позначення конфліктів, чергування рядків-зразків, межі та параметри сторінки.
Результат за замовчуванням надходить до `Docs`, а ім’я формується зі змінних
проєкту. Назви стилів FineBOM і примітки про конфлікти використовують нову назву
та англійський текст.

FineBOM автоматично не читає старі знімки середовища. Для ручного відтворення
явно задайте змінні процесу або створіть INI із секцією `[environment]` та
вкажіть його в `[plugin] environment_file`. Так вхідні дані відтворення
залишаються явними, а запуск використовує той самий API адаптера.

Новий засіб запуску може завершитися раніше за генерацію BOM. Перевіряйте `ok`
або `error` у `status.json` поточного запуску, а фактичний шлях результату —
у `report.json`. FineBOM не передає змін у схему й не змінює її.
