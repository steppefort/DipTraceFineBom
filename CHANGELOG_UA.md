# Історія змін

[English](CHANGELOG.md) · Українська

## 0.1.1

- Опублікований DipTraceSchPluginAdapter 0.1.1 підключено через його генератор.
- Закріплено коміт випуску; перевіряються версія, API та контрольна сума EXE.
- У меню DipTrace відображається FineBOM 0.1.1; ідентифікатор і назва EXE залишаються сталими.
- Версія плагіна читається з finebom/build_info.json.
- Діагностика містить обидві версії; змішані версії коду та конфігурації відхиляються.
- Типовий засіб запуску — py.exe, відповідно до робочого налаштування.

Групування BOM, оформлення та типовий шаблон BOM.ots збережено.

## 0.1.0

Перший перенос FineBOM із BOMJob 0.2.7 на спільний API адаптера.
